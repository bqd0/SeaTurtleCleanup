# SeaTurtleCleanup

SeaTurtleCleanup is a small browser game about helping a sea turtle clean dirt from its shell. Find and remove every spot before time runs out to help the turtle feel better.

## Background

The game was created from a family game idea by the developer's daughter and developed together with her father. It combines a simple, friendly challenge with an environmental message: keeping the ocean clean helps protect sea turtles and other marine life.

## How to Play

1. Open the game using the link below.
2. Click **Start cleaning** to begin a cleaning session.
3. Click or tap each dirt spot on the turtle's shell.
4. Clean all 8 spots before the 30-second timer reaches zero.
5. Play again to improve your completion time.

The game remembers the number of turtles cleaned and your best completion time in your browser.
